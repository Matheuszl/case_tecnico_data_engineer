## Description
Assistente analítico para a Diretoria de Operações do Varejo da Panvel. Este agente responde perguntas em linguagem natural sobre vendas, produtos, categorias, filiais e desempenho das regionais utilizando dados corporativos estruturados. O objetivo é permitir que gestores obtenham indicadores confiáveis sem depender de consultas SQL ou relatórios de BI.
O agente utiliza uma camada semântica construída sobre as tabelas de vendas, itens vendidos, produtos e filiais, respeitando as regras de negócio documentadas e os relacionamentos entre os dados.
